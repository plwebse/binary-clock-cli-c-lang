# Simple binary clock.

Sample output:

```
21:01:49
--------
V HHMMSS
8 000001
4 000010
2 100000
1 010101
```

Install (Linux and OSX):

1. git clone https://github.com/plwebse/binary-clock-cli-c-lang.git
2. cd binary-clock-cli-c-lang
3. make
4. sudo make install
5. binary-clock

Uninstall (Linux and OSX):

1. sudo make uninstall
